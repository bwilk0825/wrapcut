WrapCut - your site is ready to go online
==========================================

CONTENTS: index.html, wrapcut-library.json, media/ (your renamed files)

GITHUB PAGES (free, ~5 min)
1. github.com > sign in > + > New repository > Public > Create
2. Click "uploading an existing file"
3. Drag in EVERYTHING from this folder (html + json + media folder)
4. Commit changes
5. Settings > Pages > Branch: main / (root) > Save
6. Open https://YOUR-USERNAME.github.io/YOUR-REPO/

IF ITEMS SHOW "HTTP 404"
  - The file is not actually inside media/ in the repo, OR
  - the name doesn't match the JSON exactly. GitHub is CASE-SENSITIVE:
    Beach.mp4 and beach.mp4 are different files.
  - No spaces or special characters in names.
  - Use "Test all files" in the Publish tab on the live site to see
    exactly which path failed.
